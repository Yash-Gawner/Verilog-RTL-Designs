# Verilog RTL Design Projects

## Overview

This repository contains small RTL design projects implemented using Verilog HDL.

The main purpose of this repository is to practice and develop digital design, RTL coding, simulation, and hardware design skills required for FPGA and VLSI applications.

Each project includes the Verilog RTL code, testbench, and simulation details wherever applicable.

## Projects Included

### 1. Synchronous FIFO

A 16-depth, 8-bit synchronous FIFO design.

Features:
- Read and write operations
- Full and empty flag generation
- Read/write pointer management
- Simultaneous read and write support
- Verilog testbench verification


### 2. UART Communication Module

Implementation of UART transmitter and receiver.

Features:
- Serial data transmission
- FSM-based design
- Baud rate generation
- TX/RX verification


### 3. SPI Controller

SPI communication interface design.

Features:
- SPI master/slave implementation
- Clock generation
- Shift register based data transfer


### 4. I2C Controller

Implementation of I2C communication protocol.

Features:
- Start and stop conditions
- Data transmission
- ACK/NACK handling


### 5. Digital Design Modules

Collection of basic RTL designs:

- Multiplexers
- Encoders and decoders
- ALU
- Counters
- Shift registers
- FSM designs


### 6. RISC Processor

A simple RISC-based processor designed using Verilog.

Features:
- Program counter
- Instruction memory
- Register file
- ALU
- Control unit
